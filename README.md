L'objectif du TP L'objectif de ce TP est de découvrir la virtualisation à l'aide du logiciel Oracle VirtualBox et de préparer une machine virtuelle avec Ubuntu Server.

hôte : PC Logiciel de virtualisation : Oracle VirtualBox Système d'exploitation invité : Ubuntu Server Image téléchargée : fichier ISO d'Ubuntu Server
